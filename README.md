# 辟谣编年史 · RumorChronicle

> 一份可查证、带证据分级的世界谣言辟谣指南。
> 记录自工业革命以来各国常见谣言的真相与始末，追踪当代离谱传言和当下热点。

---

## 这是什么

世界上从来不缺谣言。从工业革命时期报纸煽起的恐慌，到冷战时期的政治阴谋论，再到社交媒体时代秒传万里的离谱传言，谣言从未消失，只是换了载体。

本项目想做的事很简单：**把谣言、真相、来龙去脉、证据来源，一条条写清楚**。不做情绪输出，只做可核查的记录。每条都标明证据等级，来源尽量引原始文件、权威机构声明或学术研究，不引二手转述。

## 怎么读

- **按时代读**：`book/` 下 6 个章节文件，按时间从工业革命排到当下。
- **按领域读**：每个章节内按 9 大领域分类，并按**历史研究得出的谣言热度**降序排列——翻开一章就能看到这个时期哪类谣言最多。领域列表见下方。
- **按危害读**：每条标注了危害烈度（高 / 中 / 低）。高危害的谣言造成过实际伤亡或经济损失，优先读。
- **只看最硬的**：勾选证据等级 A，只留下多方权威来源交叉证实的条目。

### 9 大领域

1. 科技与工业
2. 公共卫生与医学
3. 种族、殖民与人类学
4. 历史人物逸闻与历史叙事
5. 战争、外交与地缘政治
6. 社会风俗、道德与性别
7. 食品与农业
8. 超自然、神秘学与都市传说
9. 其他

> 不同章节的领域顺序可能不同——这正是本书的设计：按各领域在该时期的"谣言热度"排序，让时代特征一目了然。

## 每条谣言长什么样

每条都用同一套字段，方便检索和比对：

```markdown
### A-1. 喝磁化水可以治疗癌症
- **谣言**：磁化水呈小分子团，能穿透细胞壁杀死癌细胞，长期饮用可治愈癌症。
- **真相**：水的磁化不会改变其分子结构，也没有任何临床证据表明磁化水能治疗癌症。这是保健品厂商编出来的营销话术。
- **始末**：20世纪末随"磁化杯"产品兴起，借助电视购物和报纸软文在中国大陆广泛传播，后被多地市场监管部门认定为虚假宣传，但变体至今仍在中老年群体和微商中流传。
- **传播时间**：1990s — 至今
- **地域**：中国（后扩散至东南亚华人圈）
- **类别**：公共卫生与医学
- **证据等级**：A
- **危害烈度**：中（延误治疗，经济损失）
- **来源**：
  1. 中国消费者协会《部分保健用品消费警示》（2005）
  2. 国家市场监督管理总局虚假违法广告公告
- **备注**：同类变体包括"碱性水治癌""富氢水治癌"，套路一致，都是借新概念包装普通水。
```

## 证据分级

| 等级 | 含义 |
|------|------|
| **A** | 多方权威来源交叉证实：官方机构声明 + 权威媒体调查，或学术研究 + 多家独立事实核查机构一致结论 |
| **B** | 有较强证据但存在部分不确定性，或仅有单一权威来源 |
| **C** | 基于常识推理或间接证据，结论较可靠但证据不够硬 |

详见 [docs/证据分级说明.md](docs/证据分级说明.md)。

## 从哪里开始（给贡献者）

想加一条谣言，照着 [docs/条目模板.md](docs/条目模板.md) 填，提 PR 即可。新手友好的起步方向：

1. **先写你最熟悉的一条**——不用追求全面，先把模板跑通。
2. **优先高危害谣言**——造成过实际伤亡或经济损失的，价值最高。
3. **来源只引原始材料**——官方文件、学术论文（带 DOI）、有记者署名的原创新闻。二手文章不算数。
