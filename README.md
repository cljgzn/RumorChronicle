# 谬误编年史 · RumorChronicle

> 一座标签化的**事实核查知识库**：可查证、带证据分级。
> 记录自工业革命以来各国常见谣言、常见误读、民间叙事与学术分歧，追踪当代离谱传言和当下热点。

---

## 这是什么

世界上从来不缺谣言。从工业革命时期报纸煽起的恐慌，到冷战时期的政治阴谋论，再到社交媒体时代秒传万里的离谱传言，谣言从未消失，只是换了载体。

本项目想做的事很简单：**把说法的原文、溯源、核查、证据来源，一条条写清楚**。不做情绪输出，只做可核查的记录。

**存储架构**：单一物理主条目库（`book/` 六个章节文件），不拆分独立数据库；每条挂**多标签集合**，靠标签筛选生成四类逻辑视图：

- 【不实信息库】= 标签含`谣言｜完全虚假`或`伪事实｜部分虚假 / 误导`（即传统辟谣内容，各章谣言序列）
- 【历史与常识误读库】= 标签含`历史简化叙事｜常见误读`（各章「常见误读」子板块，只澄清不辟谣）
- 【民间叙事库】= 标签含`民间传说`（各章「民间叙事」子板块）
- 【学术分歧库】= 标签含`学术争议`（各章「学术分歧」子板块，只陈列各派观点不裁决）

详见 [docs/逻辑视图.md](docs/逻辑视图.md)。

## 怎么读

- **按时代读**：`book/` 下 6 个章节文件，按时间从工业革命排到当下。
- **按领域读**：每个章节内谣言序列按领域分类，并按**历史研究得出的传播热度**降序排列——翻开一章就能看到这个时期哪类不实信息最多。
- **按视图读**：按标签筛选四类逻辑库（方法见 [docs/逻辑视图.md](docs/逻辑视图.md)）；误读、民间叙事、学术分歧在各章章末子板块，不混入谣言序列。
- **按危害读**：每条标注危害等级（高 / 中 / 低）。高危害的造成过实际伤亡或经济损失，优先读。

4. 历史人物逸闻与历史叙事

## 每条目长什么样

每条都用同一套字段（原文、溯源、传播时间、来源证据、核查文本、多标签集合、危害等级、参考资料），方便检索和比对：

```markdown
### A-1. 喝磁化水可以治疗癌症
- **原文**：“磁化水呈小分子团，能穿透细胞壁杀死癌细胞，长期饮用可治愈癌症。”
- **溯源**：20世纪末随"磁化杯"产品兴起，借电视购物和报纸软文在中国大陆广泛传播。
- **传播时间**：1990s — 至今
- **来源证据**：【证据等级 A】中国消费者协会《部分保健用品消费警示》（2005）；国家市场监督管理总局虚假违法广告公告
- **核查文本**：水的磁化不会改变其分子结构，也没有任何临床证据表明磁化水能治疗癌症。这是保健品厂商编造的营销话术，后被多地市场监管部门认定为虚假宣传。
- **多标签集合**：谣言｜完全虚假
- **危害等级**：中（延误治疗，经济损失）
- **参考资料**：
  1. 中国消费者协会《部分保健用品消费警示》（2005）
- **备注**：同类变体包括"碱性水治癌""富氢水治癌"，套路一致。
```

完整模板与标签规则见 [docs/条目模板.md](docs/条目模板.md)。

## 证据分级

| 等级 | 含义 |
|------|------|
| **A** | 多方权威来源交叉证实：官方机构声明 + 权威媒体调查，或学术研究 + 多家独立事实核查机构一致结论 |
| **B** | 有较强证据但存在部分不确定性，或仅有单一权威来源 |
| **C** | 基于常识推理或间接证据，结论较可靠但证据不够硬 |

详见 [docs/证据分级说明.md](docs/证据分级说明.md)。

## 从哪里开始（给贡献者）

想加一条谣言，照着 [docs/条目模板.md](docs/条目模板.md) 填，提 PR 即可。新手友好的起步方向：

1. **先写你最熟悉的一条**——不用追求全面，先把模板跑通。
2. **优先高危害谣言**——造成过实际伤亡或经济损失的，价值最高。
3. **来源只引原始材料**——官方文件、学术论文（带 DOI）、有记者署名的原创新闻。二手文章不算数。
