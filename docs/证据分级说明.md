# 证据分级说明

本指南的核心是"可查证"。每条谣言的辟谣结论都标注证据等级，让读者一眼看出这个结论有多硬。

## 三级分级

| 等级 | 含义 | 例子 |
|------|------|------|
| **A** | 多方权威来源交叉证实 | 官方机构辟谣声明 + 权威媒体调查报道一致；或同行评议学术论文 + 多家独立事实核查机构结论一致 |
| **B** | 有较强证据但存在部分不确定性 | 单一权威来源（如政府文件）支持，但缺乏交叉验证；或证据指向明确但有个别反例 |
| **C** | 基于常识推理或间接证据 | 没有直接权威来源，但从已知事实可合理推断结论；或仅有当事人自述 |

## 来源要求

- **优先原始材料**：官方机构文件/声明、学术论文（带 DOI 或 PubMed 链接）、政府统计数据、有记者署名的原创新闻报道。
- **不引二手转述**："某公众号说""据网传"这类不作为证据来源。
- **存疑就标 C**：拿不准的宁肯标 C 并在备注里写明哪里不确定，也不要硬撑成 A。
- **官方不公开的案件**：引有记者署名的原创新闻，在备注里写明"只有媒体报道"，并附网页存档链接（web.archive.org 或 archive.ph）。

## 证据等级不等于真实性

- A 级只说明"出处可核、多方一致"，不代表结论永远正确——新证据出现时可以降级或推翻。
- 一些历史久远的谣言，原始材料已散佚，可能只能标 C，但结论本身可能是对的。
- 标注"争议"的条目，会同时列出正反两方证据。

## 危害烈度

与证据等级并列的另一个维度，衡量这条谣言造成过的实际影响：

| 烈度 | 含义 |
|------|------|
| **高** | 造成过人员伤亡、大规模社会恐慌或重大经济损失 |
| **中** | 广泛传播，导致部分人经济损失或延误正确决策 |
| **低** | 小范围流传或仅造成认知误导，无实际损害 |

一条谣言可以证据等级是 A（真相很清楚）但危害烈度是高（造成过很大伤害），两者独立。
