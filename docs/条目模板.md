# 条目模板

复制以下内容，填进对应章节的文件里。字段不要省略，不确定的写"待核实"。

```markdown
### {领域字母}-{编号}. {谣言一句话标题}

- **谣言**：{谣言的原始表述，尽量引原文，带引号。写明是谁在什么场合说的/什么载体传的。}
- **真相**：{事实是什么。一句话说清结论，再用一两句话补关键细节。}
- **始末**：{起源于何时何地、如何传播、关键转折点、最终如何被证伪/是否仍在传播。3-5 句。}
- **传播时间**：{起始年份} — {至今 / 已平息（年份）}
- **地域**：{主要传播的国家/地区，如"美国、英国"或"全球（英语圈为主）"}
- **类别**：{从以下 9 个领域中选一个：科技与工业 / 公共卫生与医学 / 种族、殖民与人类学 / 历史人物逸闻与历史叙事 / 战争、外交与地缘政治 / 社会风俗、道德与性别 / 食品与农业 / 超自然、神秘学与都市传说 / 其他}
- **证据等级**：{A / B / C}（见 [证据分级说明](证据分级说明.md)）
- **危害烈度**：{高 / 中 / 低}
- **来源**：
  1. {来源1，附链接或文件出处}
  2. {来源2，附链接或文件出处}
- **备注**：{争议点、相关谣言、变体、延伸阅读。没有可写"无"。}
```

## 填写注意

1. **谣言字段要引原文**：不要自己改写得走样。如果原文是外语，附上原文再给中文翻译。
2. **真相要给结论**：先给结论再解释，不要把结论埋在段落中间。
3. **始末要有时间线**：起源 → 传播 → 转折 → 现状，四个节点尽量都覆盖。
4. **来源要可点**：能给链接就给链接，论文给 DOI，新闻给存档链接。
5. **编号采用三级体系**：章节用中文数字（第一章、第二章…）；领域用字母 A、B、C…（按该章领域热度排序，依次分配）；领域内条目用阿拉伯数字，每个领域内从 1 开始独立编号，不跨领域连续。条目标题格式为 `### A-1. 标题`。
6. **按领域归类，按热度排序**：每条归入上述 9 个领域之一。章节内各领域按**历史研究得出的谣言热度**降序排列（领域内按传播时间升序），即根据该时期实际的谣言传播规模排序，而非简单按本章节现有条目数排序。新增条目后需检查并调整领域顺序。
