# 条目模板

本库为标签化《事实核查知识库》。**单一物理主条目库**：`book/` 下六个章节文件是唯一存储，不物理拆分多个数据库；通过**多标签体系**筛选生成逻辑视图（见 [逻辑视图](逻辑视图.md)）。

复制以下内容，填进对应章节文件。字段不要省略；无法确证的出处不要编造（见 CONTRIBUTING 来源规范）。

## 统一字段（8 个 + 可选备注）

```markdown
### {编号}. {标题}

- **原文**：{说法的原始表述，尽量引原文，带引号；写明是谁在什么场合说的/什么载体传的}
- **溯源**：{起源于何时何地、由谁或什么事件引发、沿何路径传播；含主要传播地域}
- **传播时间**：{起始年份} — {至今 / 已平息（年份）}
- **来源证据**：{核查所依据的原始证据：档案、官方统计、原始报道、学术文献。开头用【证据等级 A/B/C】标注，分级见 docs/证据分级说明.md}
- **核查文本**：{澄清或分析正文。不实条目：先给结论再讲始末；误读条目：只做史实澄清，不做辟谣定性；学术分歧条目：只陈列各派观点，不做真伪裁决}
- **多标签集合**：{从五类标签中选 1 个或多个，用中文分号"；"分隔}
- **危害等级**：{高 / 中 / 低（可带括号说明）}
- **参考资料**：
  1. {书籍《书名》+作者+出版社+年份 / 可点击 Markdown 链接 / 档案名称+收藏机构}
- **备注**：{可选。变体、交叉引用、延伸阅读}
```

## 五类标签

| 标签 | 含义 | 核查文本写法 |
|------|------|--------------|
| 谣言｜完全虚假 | 核心事实系编造、无中生有 | 明确证伪 |
| 伪事实｜部分虚假 / 误导 | 有真实内核，但关键处失真或误导 | 指出哪部分真、哪部分假 |
| 历史简化叙事｜常见误读 | 对真实事件的通俗化简化或误读（含"一夜之间""全都"式程度渲染） | 只澄清史实，不做辟谣定性 |
| 民间传说 | 民俗、超自然、都市传说类叙事 | 说明其文化来源与事实底子 |
| 学术争议 | 学界存在真实分歧 | 只陈列各派观点与证据，不裁决 |

**严禁**把通俗简化叙事、学派解读分歧标记为"谣言｜完全虚假"。

## 位置规则

1. 挂有 **谣言｜完全虚假** 或 **伪事实｜部分虚假 / 误导**（不实标签）的条目：全文保留在章节**谣言序列**（各领域 `## A.`、`## B.`…，编号 A-1、B-1…）。
2. 只挂 历史简化叙事 / 民间传说 / 学术争议（不挂不实标签）的条目：全文放入章节末尾对应子板块——`## 常见误读`（编号 `误读-N`）、`## 民间叙事`（编号 `民传-N`）、`## 学术分歧`（编号 `学争-N`），**不混入谣言条目序列**。
3. 同时挂不实标签和其他标签的条目：全文留在谣言序列，并在对应子板块放**指针条目**：
   ```markdown
   ### 民传-3. {标题}（见 {谣言序列编号}）
   {一两句说明其作为民间叙事/误读/分歧的面貌，并指向谣言序列全文。}
   ```
4. 各领域内、各子板块内均按**传播时间升序**排列；各领域按该时期传播热度降序排列。
5. 章首计数行格式：`> 本章共 X 条（谣言序列 Y 条＋子板块 Z 条）`。
