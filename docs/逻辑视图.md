# 逻辑视图

本库**物理上只有一个主条目库**（`book/` 下六个章节文件），不拆分独立数据库。四个逻辑视图靠**标签筛选**生成，只是检索视角，不产生重复存储。

## 五类标签

`谣言｜完全虚假` ／ `伪事实｜部分虚假 / 误导` ／ `历史简化叙事｜常见误读` ／ `民间传说` ／ `学术争议`

## 四类逻辑视图

| 逻辑视图 | 筛选条件（多标签集合包含） | 物理对应位置 |
|----------|---------------------------|--------------|
| 【不实信息库】 | `谣言｜完全虚假` 或 `伪事实｜部分虚假 / 误导` | 各章谣言序列（`## A.`…各领域） |
| 【历史与常识误读库】 | `历史简化叙事｜常见误读` | 各章「常见误读」子板块（误读-N），另含谣言序列中兼挂此标签的条目 |
| 【民间叙事库】 | `民间传说` | 各章「民间叙事」子板块（民传-N），另含谣言序列中兼挂此标签的条目 |
| 【学术分歧库】 | `学术争议` | 各章「学术分歧」子板块（学争-N），仅陈列各派观点，不做真伪裁决 |

## 两种读法

1. **编年阅读**：按 `book/` 六章顺序读，章节内谣言序列按领域（热度降序）、领域内按传播时间升序；子板块附于章末。
2. **视图检索**：按标签筛选。例如在仓库根目录：
   - 不实信息库：`grep -l "谣言｜完全虚假\|伪事实｜部分虚假" book/*.md`，或按条目查 `grep "多标签集合.*谣言｜完全虚假" book/*.md`
   - 误读库：`grep "多标签集合.*历史简化叙事" book/*.md`
   - 民间叙事库：`grep "多标签集合.*民间传说" book/*.md`
   - 学术分歧库：`grep "多标签集合.*学术争议" book/*.md`

## 一致性约定

- 一条目挂不实标签 + 其他标签时：全文在谣言序列，子板块内为指针条目（`（见 X-N）`），两边编号互相可查。
- 子板块条目只做澄清/陈列，不进入不实信息逻辑视图，不使用"辟谣/证伪"定性措辞。
