# 辟谣方法论

> 不是学术论文，是给写条目的人看的实操手册。

## 怎么判断一条信息是不是谣言

谣言不等于"错误信息"。谣言的核心特征是：**未经证实却被当作事实传播**。所以写条目时先问三个问题：

1. 这条信息有没有被证实？（有没有原始出处、权威来源？）
2. 它是不是被当作事实在传？（如果明确标注是"玩笑""虚构"则不算）
3. 它造成了什么影响？（没人传的错误信息不值得收录）

三个都是"是"，就值得写。

## 怎么查真相

按优先级走：

1. **官方机构**：政府部门、WHO、CDC、各国统计局、监管机构的声明和报告。
2. **学术文献**：PubMed、Google Scholar、知网等，优先同行评议的论文和荟萃分析。
3. **权威媒体调查**：有记者署名、经过编辑审核的原创新闻。通讯社（路透、AP、新华社）优先于自媒体。
4. **事实核查机构**：Snopes、PolitiFact、Full Fact、腾讯较真、澎湃明查等。注意：事实核查机构的结论是二手的，最好再回到它引用的原始来源。
5. **当事人自述**：优先级最低，只能作为旁证。

## 常见谣言套路

写多了会发现谣言反复用同一套手法，识别它们能帮你快速判断：

- **借权威包装**："某专家说""NASA 证实""哈佛研究"——查一下那个专家/机构有没有说过。
- **偷换概念**：把"相关性"说成"因果"，把"动物实验"说成"对人有效"。
- **制造恐慌**："再不看就删了""震惊！""紧急通知"——情绪越激烈越要查。
- **无法证伪**："政府隐瞒了""你没见过不代表没有"——无法证伪的命题不是科学命题。
- **幸存者偏差**：只举成功案例，不提失败的。

## 写条目时的纪律

- **不站队**：只陈述事实和证据，不在条目里输出个人观点。
- **不替读者下结论**：把证据列清楚，让读者自己判断。
- **不传播谣言本身**：谣言字段引用原文即可，不要展开描述细节，避免二次传播。
- **标注时效**：有些谣言的真相会随时间变化（比如疫情期间的信息），写清楚结论的时间点。
